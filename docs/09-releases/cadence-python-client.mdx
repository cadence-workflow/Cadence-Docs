The Cadence Python client is published on PyPI as [`cadence-python-client`](https://pypi.org/project/cadence-python-client/) and follows [semantic versioning](https://semver.org/spec/v2.0.0.html). See the Python client's [GitHub Releases](https://github.com/cadence-workflow/cadence-python-client/releases) for changes between versions.

:::tip[Latest release]

> <strong><a href={latestRelease.html_url} target="_blank">{latestRelease.tag_name}</a> </strong>published on {latestRelease.published_at_date}

:::

:::note[0.x release line]

The Python client has not reached 1.0. Semantic versioning treats 0.x as initial development, where any release can include breaking changes, so read the release notes before you upgrade.

:::

:::info[Python Compatibility]

Python versions 3.11, 3.12 and 3.13 are supported at this time.

:::

Cadence Python Client Releases

The Cadence Python client is published on PyPI as cadence-python-client and follows semantic versioning. See the Python client's GitHub Releases for changes between versions.

Latest release

v0.4.1 published on 2026-09-30

0.x release line

The Python client has not reached 1.0. Semantic versioning treats 0.x as initial development, where any release can include breaking changes, so read the release notes before you upgrade.

Python Compatibility

Python versions 3.11, 3.12 and 3.13 are supported at this time.

Release v0.2.2 published by timl3136 on 2026-05-04​

What's Changed

This release adds several workflow and activity execution features, improves cross-cluster support, and updates the client's generated Cadence IDL bindings.

New Features

  • Workflow ID reuse policy support
    Added support for configuring workflow ID reuse behavior when starting workflows. This allows callers to control how Cadence handles new workflow executions that reuse an existing workflow ID.

  • Activity retry policy support
    Added RetryPolicy definitions, proto type mapping, and integration with activity options, enabling activities to be configured with retry behavior directly from the Python client.

  • Workflow retry support
    Added retry policy support for workflow executions, allowing workflows to be automatically retried according to configured retry settings.

  • Workflow signal handling
    Added support for handling workflow signals, enabling workflows to receive and react to external signals during execution.

  • Active-active support
    Added client-side support for active-active Cadence deployments.

Improvements

  • Updated Cadence IDL bindings
    Updated cadence-idl to match the current Cadence server HEAD, keeping generated API types aligned with the server.

  • Activity retry integration tests
    Added integration test coverage for activity retry behavior.

  • Build fixes
    Fixed Makefile dependency handling to ensure required dependencies are installed correctly.

Release v0.1.0 published by timl3136 on 2026-01-13​

cadence-python-client v0.1.0

This is the initial release of the Cadence Python Client.
It provides the core functionality required to build and run Cadence workflows and activities in Python.

Features

  • Workflow and activity registration via definitions
  • Deterministic workflow execution
  • Workflow completion, failure, and signaling support
  • Activity scheduling from workflows
  • Client APIs for starting and signaling workflows
  • gRPC-based Cadence service client with retries and error mapping
  • Default DataConverter aligned with the Cadence Go client

Build, Test, and Tooling

  • Python project setup using pyproject.toml
  • Protobuf and gRPC code generation
  • Linting, formatting, and type-safety checks
  • Unit and integration tests

Note: This release is a v0.1.0 and the API is not yet stable. Breaking changes may occur in future releases.
